## Implementation Steps (8 steps, using team parallel where possible)

### Step 1 — Generate unstructured data (Python script)

Create `data/generate_unstructured.py` that reads existing CSVs and produces:

**a) Policy summary documents** (~250 rows, one per policy):
- Combines customer name + policy details + coverages into a natural-language document
- Fields: `doc_id`, `customer_id`, `policy_id`, `doc_type='policy_summary'`, `title`, `content` (full text), `created_at`
- Example content: *"Policy POL-000001 — Auto Insurance for Maria Chen. Effective 2025-09-11 to 2026-09-11. Annual premium: $1,200.00, paid monthly. Coverages: Liability ($219,000 limit, $0 deductible), Collision ($54,000 limit, $1,600 deductible), Comprehensive ($65,000 limit, $1,000 deductible)."*

**b) Customer emails** (~100 rows, one per email-type interaction + new synthetic ones):
- Realistic customer emails: complaints, inquiries, renewal questions, claim follow-ups
- Fields: `doc_id`, `customer_id`, `interaction_id`, `doc_type='email'`, `title` (subject line), `content` (email body), `created_at`

**c) Enriched transcripts** (reformat existing 50 transcripts):
- Fields: `doc_id`, `customer_id`, `interaction_id`, `doc_type='transcript'`, `title`, `content`, `created_at`

**d) Knowledge base articles** (~10 rows):
- Internal SOPs: "How to handle a retention call", "Escalation procedure for complaints", "Cross-sell eligibility rules", "Renewal discount policy", etc.
- Fields: `doc_id`, `customer_id=NULL`, `doc_type='knowledge_base'`, `title`, `content`, `created_at`

All output to `data/generated/unstructured_documents.csv`.

### Step 2 — Create RAW table for unstructured documents

New SQL file `sql/01_raw/05_unstructured_tables.sql`:
```sql
CREATE TABLE RAW_DOCUMENTS (
    doc_id         VARCHAR(30)   NOT NULL,
    customer_id    VARCHAR(20),            -- NULL for knowledge base articles
    policy_id      VARCHAR(20),            -- NULL for non-policy docs
    interaction_id VARCHAR(20),            -- NULL for non-interaction docs
    doc_type       VARCHAR(30)   NOT NULL, -- policy_summary, email, transcript, knowledge_base
    title          VARCHAR(500)  NOT NULL,
    content        VARCHAR       NOT NULL, -- full text content
    created_at     TIMESTAMP_NTZ NOT NULL,
    _loaded_at     TIMESTAMP_NTZ DEFAULT CURRENT_TIMESTAMP()
);
```

### Step 4 — Create Cortex Search Service

New SQL file `sql/10_search/01_cortex_search_service.sql`:
```sql
CREATE OR REPLACE CORTEX SEARCH SERVICE CUSTOMER360_DB.ANALYTICS.SVC_CUSTOMER_DOCS
  ON content
  PRIMARY KEY (doc_id)
  ATTRIBUTES customer_id, doc_type, policy_id, title
  WAREHOUSE = CUSTOMER360_WH
  TARGET_LAG = '1 hour'
AS
  SELECT doc_id, customer_id, policy_id, interaction_id,
         doc_type, title, content, created_at
  FROM CUSTOMER360_DB.RAW.RAW_DOCUMENTS;
```
