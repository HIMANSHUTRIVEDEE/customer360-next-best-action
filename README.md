\# Customer360 AI — Next Best Action Engine



\## Challenge



Build an enterprise-ready application that combines structured customer

data and unstructured interactions—including call transcripts—to create

a unified Customer 360 view and recommend the Next Best Action.



\## Proposed Solution



Customer360 AI will:



1\. Unify customer, policy, claim, payment and interaction data.

2\. Enrich call transcripts with summaries, sentiment, intent and urgency.

3\. identify transparent customer-retention and service-risk signals.

4\. Recommend an evidence-backed Next Best Action.

5\. Route low-confidence or restricted actions for human review.

6\. Present insights and actions through a Streamlit application.



\## Primary Users



\- Customer service representative

\- Retention specialist

\- Insurance advisor

\- Customer experience manager



\## Core Demonstration



Customer question → Customer 360 context → AI insight →

Next Best Action → Human-approved action
